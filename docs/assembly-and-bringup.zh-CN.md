# 装配、烧录与首板调试

对象为一台 Calxus 工程样机。按随附 PCB 版本、BOM 和坐标文件制造；本说明用于线束、服务接口、烧录和首板验收，不能替代实际 ERC/DRC、封装核对及板厂工艺文件。

## 装配前核对

- TUSB3410 采用 `TUSB3410RHBR`，RHB/VQFN-32 5×5 mm，供应编号 `C2679332`。不能拿 LQFP-32 版本代换其封装。实际嘉立创库将裸露焊盘编号为 33，接 GND；芯片 1 脚方向须核对。
- CH343P 采用 QFN-16，实际嘉立创库将裸露焊盘编号为 17（数据手册称 0），接 GND；CH444G 为 SOP-16。CH343P 与 CH343G/C/K 的针脚不能互换。
- EEPROM 为 `24LC64-I/SN`、SOIC-8，容量 8192 字节。保留正常读启动连接及外部编程所需隔离点，WP 正常为写保护状态。
- USB-C 的 CC1、CC2 各有独立 5.1 kΩ 下拉；重复 D+/D−、VBUS/GND 焊盘按实际器件库分组核对。Mini-B 尾线的 ID 悬空。
- 对照制造输出核实二极管、三极管、稳压器、晶体与 USB ESD 阵列方向。厂商脚号是依据，不能仅凭外观旋转。
- 回流后先显微检查 QFN 周边和连接器；线束、跳帽与机壳在电气检查后安装。必要时对 TUSB 底部焊盘作 X-ray 或工艺验证。

## UART 线束和选择

J6 为带防呆的 AUX 四针接口。针号按 PCB 标记；从插头线侧观察的左右顺序可能与板上顶视图相反。

| J6 针号 | 连接 |
|---:|---|
| 1 | GND |
| 2 | 计算器 TX → Calxus RX |
| 3 | Calxus TX → 计算器 RX |
| 4 | NC；不接计算器电池触点 |

本版 UART 使用 3.3 V 逻辑域、非反相、空闲高。TX 经开漏缓冲和 10 kΩ 上拉释放高电平；上拉电源经过 D16 防反灌二极管，仅由本机上拉时 TX 高电平约 3.0–3.2 V；计算器自身上拉和尾线负载可改变该电平。RX 经耐受外部输入的缓冲器进入 CH343P。高电平上升速度受尾线电容和上拉影响，应在计算器实际接入状态下测波形；不能只用板上空载回环给整条线确定最高波特率。

串口支路需要将 RX 与 TX **成对**选到 CASIO 或 AUX；不能一根选 CASIO、另一根选 AUX，也不能把两台计算器的发送端并在一起。跳线式 J7 的定义为：

| J7 针号 | 网络 |
|---:|---|
| 1 | CASIO_RX：Tip，计算器 TX |
| 2 | CASIO_TX：Ring，计算器 RX |
| 3 | 公共 UART_RX_EXT |
| 4 | 公共 UART_TX_EXT |
| 5 | AUX_RX |
| 6 | AUX_TX |

CASIO：短接 1–3 与 2–4。AUX：短接 3–5 与 4–6。全取下为 OFF。若本次装配采用外壳侧面的双刀机械选择器，其两组触点必须实现同样的成对选路，并在装配后用万用表逐档核对。切换前断开上行 USB。

本版 CASIO 固定尾线以**最终插入计算器的公头**为准：Tip → CASIO_RX，Ring → CASIO_TX，Sleeve → GND。每条线用万用表从 PCB 焊点量到公头金属触点。原厂 SB-62 计算器互连线为交叉线；若裁切旧线制作尾线，应测剩余公头端，不直接照用另一端的线色或母座标注。该定义与原作者实测项目的直插线接法一致，来源见[技术来源](sources.md)。

固定 TI 尾线与固定 CASIO 尾线分别标记，不共用同一个未标识的 2.5 mm 插头。HP/Nspire 尾线另外记录计算器侧顶视图、端子号与线色，不用“红线一定是 TX”之类颜色假设。

## EEPROM 编程接口

J8 为六个编程/探测焊盘：

| J8 针号 | 信号 | 说明 |
|---:|---|---|
| 1 | EE_VCC | EEPROM 3.3 V 电源；不是 5 V |
| 2 | GND | 编程器地 |
| 3 | EE_SCL | EEPROM 时钟侧 |
| 4 | EE_SDA | EEPROM 数据侧 |
| 5 | EE_WP | 拉低允许写入 |
| 6 | TUSB RESET，低有效 | 复位测试点；外部独立 EEPROM 编程时可不接 |

外部编程前拔下全部 USB 和计算器，在断电状态断开 SDA 的 R23、EEPROM 电源 R25，并打开 J9 SCL 服务跳帽，使 EEPROM 与主板 MCU 总线、电源隔离。编程器使用 3.3 V；WP 拉低。完成全片写入、读回比对后先断编程器电源，再恢复服务连接。R23/R25 的拆装只在断电时进行。

J9 的 1 脚为 SIL_SCL（TUSB3410 第 11 脚），2 脚为 EE_SCL（24LC64 第 6 脚）；正常使用装跳帽，进入 ROM 恢复时打开。24LC64 的 A0/A1/A2 均接地，正常 I²C 地址为 `0x50`。

USB Burner 路径保留 R23/R25，不需要拆焊：上电前打开 J9 SCL 服务跳帽，待 ROM 引导和烧录 HID 固件加载完成，再装回跳帽；用完整镜像方式写入并读回。J10 为 WP 写使能，短接时拉低 WP，正常使用取下以恢复写保护。详细顺序及文件选择见[固件说明](../firmware/README.md)。

## 首次上电顺序

1. 不连接计算器、外设和尾线。用万用表确认 VBUS、3.3 V、1.8 V 对地无短路；USB D+/D− 不短接到 VBUS。
2. 设置原生档 `00`，先用带电流显示和限流功能的 USB 测试连接上电。记录空载电流；此档应仅有 VBUS_NATIVE 供电，5V_SERIAL、3V3 与 TUSB 1.8 V 不应因正常电源路径而上电。断电后依次验证 `01` 只供电 VBUS_USBA；记录未选支路残压，若仍接着计算器应另查反供电。
3. 断电切到 `10`，重新上电测 5V_SERIAL、3V3、TUSB 1.8 V，并检查复位释放、12 MHz 晶体起振和 SUSPEND/VREGEN 网络。此档 TUSB3410 与 CH343P 均有电，只有 TUSB 的 USB 数据被选中。异常发热、周期复位或大电流时立即断电；测晶体使用低电容探头。
4. 将 SCL 跳帽打开，主档设 `10` 后重新上电，检查 ROM `0451:3410`；按固件文档写 EEPROM 并读回。
5. 恢复 SCL 与写保护，重新上电检查 SilverLink `0451:E001`。记录主机实际读到的描述符、驱动和供电电流。
6. 在 `11` 档分别进行 CASIO/AUX 路径连通与串口回环。先检电平和 RX/TX 方向，再连接计算器。
7. 分别验证 `00`、`01`、`10`、`11`；每次退出软件、断开上行、切档、再连接。记录选中路径和未选中路径状态。
8. 实测空载、正常传输、挂起、恢复和各外设负载下的总电流与 VBUS 压降。把所选 USB 设备声明的电流与整机电流比较；不能只比较一个芯片的典型电流。SilverLink 参考配置描述符声明 100 mA。

## 首次接计算器

TI Link 先用示波器核对 Tip/Ring 的空闲、拉低、释放，再只做读目录和小文件双向传输。CASIO 使用软件明确支持 COM 的具体机型。HP 接入前确认专用端子的地、TX、RX，电池触点不接；单独记录关机及关闭 IO 时行为。Nspire 先只接地和计算器 TX 来收日志，确认电平后再考虑发送路径。

每个机型都记录软件版本与文件校验结果；不在首次验收中使用计算器系统刷写作为连通性测试。转换器 EEPROM 的恢复测试与计算器系统升级是两件独立工作。

## 装壳检查

PCB 目标外形 80×42 mm，外壳目标包络 86×48×19 mm；以最终机械文件尺寸为准。先试装 PCB、上行 USB-C、USB-A、选档件和全部线束，确认螺柱、焊点、壳壁和线缆弯曲半径没有干涉。线束夹持处承受拔插力，焊盘不作为拉力支撑。复位/烧录焊盘保持可服务，恢复跳帽不被壳体压短到相邻节点。

封壳前拍摄板上器件面、焊接面、每条尾线针序与跳帽状态，随样机编号保存。按[验证记录](validation-record.zh-CN.md)填写实际结果后再判定该样机通过。
