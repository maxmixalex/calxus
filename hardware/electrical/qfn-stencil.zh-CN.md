# QFN 裸焊盘钢网核查

本文件只处理 U2/TUSB3410 与 U3/CH343P 裸焊盘的锡膏开口。方案数据见 [ep_stencil_proposal.json](ep_stencil_proposal.json)。已读取当前项目的原生封装源，确认两颗EP自动锡膏开口均已禁用，但各有一个独立缩小的单窗；尚未分窗。四窗归档补丁已准备并通过离线保护校验，仍须导入新本地项目及最终Paste Gerber验证。

| 项目 | U2：TUSB3410RHBR，EP=33 | U3：CH343P，原厂0号/本地EP=17 |
|---|---|---|
| 实际库铜焊盘 | 3.50×3.50mm | 1.70×1.70mm |
| 依据 | TI 专用 RHB0032E 钢网示例 | 本项目工艺选择；未在已审 WCH CH343 V2.0 与封装资料中发现专用钢网规则 |
| 锡膏窗口 | 2×2，共4个1.49×1.49mm窗 | 2×2，共4个0.65×0.65mm窗 |
| 每窗圆角 | R0.05mm | R0.05mm |
| 相对EP中心的窗中心 | (±0.845, ±0.845)mm | (±0.425, ±0.425)mm |
| 两窗之间钢网桥 | 0.20mm | 0.20mm |
| 相对本库铜面积的覆盖率，计圆角 | 72.423% | 58.181% |
| 几何开口面积合计 | 8.871816mm² | 1.681416mm² |

TI TUSB3410 官方数据手册附录 RHB0032E、图号4223442/B（08/2019）、PDF第103页，直接给出了四个1.49mm窗口、上述中心偏移和R0.05mm；该示例按0.125mm厚钢网设计，配其3.45mm方形EP标注约75%印膏覆盖。这里保持原厂窗口几何，按本库3.50mm铜面积重算比例，没有把铜焊盘悄悄改成3.45mm。

CH343P 的0.65mm四窗是针对本库1.70mm铜焊盘的工程选择。依据是 TI 通用 QFN/SON 装联指南 SLUA271C 第4.4节给出的典型50–70%中心焊盘印膏覆盖范围，用于减少整块1:1印膏可能导致的锡量过多与器件浮高。**这不是 WCH 对 CH343P 的认证开口或生产验收值。** WCH旧版常用封装图QFN16-3×3给出器件本体EP约1.8mm，它是器件尺寸图，不是PCB铜焊盘或钢网模板。

原生U2.33、U3.17的topPasteMask/bottomPasteMask均为−3937，自动开口已经被禁用。U2项目封装6d6747048cb070d5的e15是约2.80×2.80mm单窗；U3项目封装c020f55e3a184cd3的e47是约1.36×1.36mm单窗，几何面积各约为铜面积64%。这些独立Top Paste填充仍会输出锡膏，不能把负扩展值误判为EP完全没有锡膏。

使用 [patch_native_ep_stencil.py](../../tools/patch_native_ep_stencil.py) 对**布线后新导出的项目.epro2副本**处理：只替换这两条原单窗FILL，各新增3条，共4窗；保留完整 GND 铜焊盘、原有网络、阻焊、自动paste禁用属性及32/16个外围引脚锡膏FILL。归档补丁不修改全局器件库。除2条目标记录和6条新记录外，所有源码原始行字节保持；其他ZIP条目与输入文件保持不变。可先执行叠层补丁，再执行此补丁，随后正式导入为新本地EPRJ3并保存、关闭、重开。不能把 paste expansion=0 理解为“无锡膏”，因为零扩展通常仍是1:1开口；也不能在整块EP开口上叠加四窗后就称为分窗。周边信号焊盘的锡膏不在本次修改范围。

四个 EP 内过孔仍按已经明确的 **树脂填孔、研磨平整、盖铜 VIPPO** 制造；分窗不能替代盖铜填孔。TI示例中对过孔处理的一般提示不改变本项目已经锁定的VIPPO要求。

0.125mm是TI示例的厚度依据。整板钢网最终厚度还需在实际组装工程文件中落实，并与全板最细引脚开口的脱模条件一致；不把示例厚度直接当作嘉立创已经确认的制造参数。首件用印膏检查与回流后X-ray确认中心焊点分布、虚焊/浮高，不能把印膏面积比例等同于焊后有效接触面积。

原生验证必须读取 U2.33/U3.17 的 pasteMask/solderMask 属性及所属封装的独立 Top Paste 图元，再渲染最终导出的 Paste Gerber，确认每个EP区域恰有四窗且没有满面积开口叠加。原始证据位于validation/usb-manual-copper-audit/qfn-footprint-sources.json，取自实际项目封装UUID；不是只含铜几何的eda_parts_catalog_full.json。最终Gerber验证完成前不把离线补丁标记为已实施。
