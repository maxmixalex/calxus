# USB 2.0 差分阻抗与 JLC 叠层

本版选择 JLCPCB **JLC04161H-7628**：4层、名义1.6mm、外铜1oz、内铜0.5oz、Nan Ya NP-155F。高速主干走L4、参考连续L3地；连接器/CH444附近短扇出走L1、参考连续L2地。两侧外层截面与介质相同，采用同一线宽/间距；这是由对称叠层推导，计算器的原始请求为L1微带。L2和L3均保持连续GND。

| 层/介质 | 厚度 | 电气参数 |
|---|---:|---|
| L1铜 | 图表0.035mm | 计算模型T1=1.6mil |
| L1–L2 7628预浸料 | 0.21040mm | Er=4.4 |
| L2铜 | 0.0152mm | 地平面 |
| L2–L3芯板 | 1.065mm | 当前模板Er=4.38，静态网页列4.6；不参与此L1微带计算 |
| L3铜 | 0.0152mm | 连续地平面 |
| L3–L4 7628预浸料 | 0.21040mm | Er=4.4 |
| L4铜 | 图表0.035mm | 高速差分主干，参考L3 |

2026-11-21向JLC官方计算器服务提交外层、带阻焊、非共面差分模型，目标90Ω、边缘间距S1=6mil，返回：

- 底宽W1=9.53125mil=0.24209375mm。
- 顶宽W2=9.03125mil。
- 计算差分阻抗90.128929Ω，status=0且resultValid=1。
- 布线规则采用 **线宽0.242mm、两线边缘间距0.1524mm**。
- 将线宽舍入至0.242mm后，官方正向计算返回90.142084Ω，status=0且resultValid=1。
- 实际指令保留9.53125mil线宽，避免二次舍入。

同层铺铜与该对保持至少0.65mm距离，使非共面微带假设合理。差分对长度差控制在0.254mm（10mil）内；这是本项目保守布局目标，不是声称USB规范的唯一限制。本次每条支路使用两组对称信号过孔，均在旁边提供地回流过孔；每条完整选通路径包含四次信号换层。D1/D2/D3按流通连接，缩短保护器和连接器到主通路的分支；不要在高速线上加测试支桩。

本次计算输入为H1=8.2834646mil、Er1=4.4、T1=1.6mil、C1=C3=1.0mil、C2=0.6mil、CEr=3.8，底/顶线宽差0.5mil。当前官方配置API与静态说明页中旧的1.2mil阻焊、0.7mil刻蚀差不同；旧订单页的7.1mil压合高度也与当前模板/计算器不同。本次遵循实时计算器脚本所读取的配置和模板，并保存完整请求/返回以供复核。不能把旧值与新结果混用。

采购时必须明确选择上述叠层和阻抗控制要求，交由板厂复核实际制造线宽与coupon。软件计算不能证明成板阻抗、CH444/ESD/尾线组合的480Mbps眼图或USB合规性。
